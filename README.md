# Portfolio - Tolotra Nomenjanahary Randrianantenaina

Portfolio personnel bilingue (FR/EN) d'un développeur Fullstack moderne et élégant, construit avec React, TypeScript et Tailwind CSS.

## 🚀 Technologies

- **React** 18.3.1
- **TypeScript** 5.5.3
- **Vite** 5.4.2
- **Tailwind CSS** 3.4.1
- **Lucide React** (icônes)

## 📁 Structure du Projet

```
src/
├── components/
│   ├── Header.tsx       # Navigation et changement de langue
│   ├── Hero.tsx         # Section d'accueil avec photo
│   ├── About.tsx        # Section à propos
│   ├── Skills.tsx       # Compétences techniques
│   ├── Experience.tsx   # Expérience professionnelle
│   ├── Projects.tsx     # Projets réalisés
│   ├── Education.tsx   # Formation
│   ├── Contact.tsx     # Formulaire de contact
│   └── Loader.tsx       # Animation de chargement
├── contexts/
│   └── LanguageContext.tsx  # Gestion de l'internationalisation
├── assets/
│   └── profile-photo.png    # Photo de profil
├── App.tsx
├── main.tsx
└── index.css
```

## 🎨 Design System

- **Couleur principale** : Midnight Blue (#0B1120)
- **Couleur secondaire** : Beige (#F5E6D3)
- **Couleurs d'accent** : Brown (#8B5A3C) et Garnet (#991B1E)
- **Style** : Moderne, minimaliste, élégant, orienté tech
- **Animations** : Transitions fluides, effets de survol, révélations au scroll

## 🛠️ Installation

```bash
npm install
```

## 🚀 Démarrage

```bash
npm run dev
```

L'application sera accessible sur `http://localhost:5173`

## 📦 Build de Production

```bash
npm run build
```

Les fichiers optimisés seront générés dans le dossier `dist/`

## 🔍 Scripts Disponibles

- `npm run dev` - Démarre le serveur de développement
- `npm run build` - Construit l'application pour la production
- `npm run preview` - Prévisualise le build de production
- `npm run lint` - Vérifie le code avec ESLint
- `npm run typecheck` - Vérifie les types TypeScript

## 📄 Sections du Portfolio

1. **Hero** - Présentation avec photo de profil et CTA
2. **About** - Description professionnelle
3. **Skills** - Compétences techniques organisées par catégories
4. **Experience** - Expérience professionnelle en freelance
5. **Projects** - Projets phares avec descriptions détaillées
6. **Education** - Formation académique
7. **Contact** - Formulaire de contact et liens sociaux

## 🌍 Internationalisation

Toutes les traductions sont gérées via le contexte `LanguageContext.tsx`. Le système utilise des clés de traduction avec la notation par points (ex: `hero.title`, `nav.about`).
